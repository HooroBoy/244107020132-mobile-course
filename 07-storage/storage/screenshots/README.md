# Bukti Screenshot

Folder ini disiapkan untuk bukti uji manual pada emulator atau perangkat Android. Screenshot tidak dibuat otomatis agar bukti mode pesawat, persistensi, dan hasil sinkronisasi tetap autentik.

Daftar nama berkas dan skenario pengambilan tersedia di [`docs/uji-offline.md`](../docs/uji-offline.md).
